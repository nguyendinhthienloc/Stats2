# Legacy midterm archive

This directory preserves the completed Applied Statistics II midterm project on body-fat prediction with Ridge, Lasso, Elastic Net, and random neural features.

The archive retains its original README, dependency lockfile, analysis, report, generated outputs, submission package, and team notes. Run legacy commands from this directory so its relative paths and `renv` environment remain valid.

Do not use legacy outputs as final-project results. Reusable ideas should be reimplemented in the active root with the Wine Quality data and the final-project evaluation protocol.
