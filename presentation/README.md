# Presentation

Create the 10-minute final presentation here. The preferred final filename is `final-presentation.pdf`; the release workflow includes it automatically when present.

Suggested timing:

1. Problem, data, and research questions - 1 minute.
2. Part 1 EDA and cleaning decisions - 2 minutes.
3. Regularization and held-out comparison - 3 minutes.
4. Part 2 design, effects, and diagnostics - 3 minutes.
5. Conclusions and limitations - 1 minute.
